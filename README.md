# Supermercado - Desarrollo Frontend II

Este es mi proyecto de la sumativa de la semana 3 del ramo **Desarrollo Frontend II (PFY2202)** de DUOC UC.

Hice una página de supermercado con React que permite:

- Ver el inventario y filtrar los productos por categoría.
- Buscar productos y revisar sus detalles.
- Agregar productos nuevos al inventario.
- Agregar artículos al carrito y cambiar las cantidades.
- Actualizar automáticamente el stock al usar el carrito.

Usé **React, React Router, Tailwind CSS y Vite**. Los datos quedan guardados en el navegador, así que no hace falta tener una base de datos.

## Cómo ejecutar el proyecto

1. Abrir la carpeta en VS Code.
2. Abrir la terminal y escribir `npm install`.
3. Ejecutar `npm run dev`.
4. Entrar al enlace local que muestra la terminal (generalmente `http://localhost:5173`).

Para ejecutar las pruebas: `npm test`.

## GitHub Pages

Después de subir el proyecto a GitHub, se puede publicar con `npm run deploy`. En la configuración del repositorio, seleccionar la rama `gh-pages` como fuente de GitHub Pages.

**Nota:** Los productos, precios y datos de contacto son de ejemplo. En el inicio hay una opción para reiniciar los datos de prueba.
